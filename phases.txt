ALGORITHM SELECTION (FIXATED & FINALIZED):
1. Tabular ML (Dissatisfaction Risk & Driver Attribution):
   - Model: LightGBM Classifier (LGBMClassifier)
   - Explainability: Tree Feature Importance (gain/split) + TreeSHAP
   - Target: Binary flag `is_low_score` (1 if review_score <= 2, else 0)
   - Features: delay_days, transit_days, freight_ratio, product_volume_cm3, 
               product_weight_g, is_interstate, item_price, complaint_topic_tag
2. NLP Text Classification (Review Root-Cause Categorization):
   - Model: TfidfVectorizer (Portuguese stopwords, ngram_range=(1,2), max_features=5000) 
            + Multiclass LogisticRegression(class_weight='balanced', max_iter=1000)
   - Classes (4):
     * DELIVERY_DELAY ("atraso", "demorou", "prazo", "nao chegou")
     * DAMAGED_DEFECTIVE ("quebrado", "defeito", "estragado", "pessima qualidade")
     * CATALOG_MISMATCH ("tamanho errado", "cor diferente", "veio errado", "propaganda enganosa")
     * SERVICE_REFUND ("nao respondem", "cancelamento", "estorno", "atendimento péssimo")
3. Semantic Vector Search (Qualitative RAG):
   - Embedding Model: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
     (Multilingual dense 384-d vectors, native Portuguese support, runs CPU/local)
   - Vector Store: ChromaDB (Local persistent sqlite/parquet, zero cloud cost)
4. LLM Operational Reasoning (Action Copilot):
   - Primary Free Provider: Groq API (model: llama-3.3-70b-versatile or llama-3.1-8b-instant)
     (Generous free tier, sub-second latency, strict JSON object output mode)
   - AMD Hardware Bridge: Pluggable adapter in backend configuration allowing 1-line 
     toggle to Fireworks/AMD Instinct (`LLM_PROVIDER=groq` -> `LLM_PROVIDER=fireworks`)
